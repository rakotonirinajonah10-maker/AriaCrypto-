# AriaCrypto 🇲🇬
Échange Crypto ↔ Ariary Malagasy

## Fichiers
- `index.html` - Site d'échange MGA ↔ Crypto (Supabase + Orange Money)
- `admin-v2.html` - Dashboard Admin (Validation + SMS + Graphiques)

## Installation
1. Crée un projet sur Supabase
2. Crée la table `transactions`
3. Remplace SUPABASE_URL et SUPABASE_KEY dans les 2 fichiers
4. Mets ton token Orange Money API
